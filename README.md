# Retail Sales Analysis

## Project Overview
This project analyses retail sales data to identify sales trends, top-performing products, category performance, and customer spending patterns.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
- 1,000 transactions
- 100 customers
- 8 original columns

## Key Findings
- **Total Revenue:** 2,754,266.60
- **Total Units Sold:** 5,571
- **Total Transactions:** 1,000
- **Total Customers:** 100
- **Average Sales:** 2,754.27
- **Highest Revenue Month:** September 2024
- **Top Revenue Product:** Headphones
- **Top Revenue Category:** Clothing
- **Highest Spending Customer:** Customer 94
- **Most Purchased Product:** Jeans

## Data Analysis
The project includes:
- Data inspection and cleaning
- Missing value and duplicate checks
- Monthly sales analysis
- Product and category analysis
- Customer spending analysis
- Correlation analysis
- Outlier detection
- Data visualization and dashboard creation

## Project Files
- `Project_2_Retail_Sales_Analysis.ipynb` – Python analysis notebook
- `Retail_Sales_Cleaned.csv` – Cleaned dataset
- `Retail_Sales_Dashboard.png` – Sales dashboard

## Conclusion
The analysis provides insights into retail sales performance, customer behaviour, and product trends. These findings can help support better business decisions.
